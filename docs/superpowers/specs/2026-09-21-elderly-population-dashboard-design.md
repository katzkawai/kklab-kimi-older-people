# 日本の高齢者人口ダッシュボード — 設計書

- 日付: 2026-09-21
- ステータス: 承認済み (ユーザー承認 2026-09-21)
- 目的: 総務省統計局の最新人口データ(高齢者人口)を収集・可視化し、GitHub Pages で公開する

## 背景・スコープ

- 対象データ: 高齢者(65歳以上)人口に絞る (ユーザー選択)
- ページ構成: ダッシュボード型 (要約カード + 推移 + 都道府県ランキング + 内訳 + 国際比較、1ページに網羅。ユーザーがブラウザモックで選択)
- 更新方法: 今回だけの静的ページ (自動更新は作らない。ユーザー選択)
- 実装方式: Python でデータ抽出 → 自己完結の静的 index.html 生成 (ユーザー選択)

## データソース (調査済み・APIキー不要の直接ダウンロード)

1. **統計トピックス No.146「統計からみた我が国の高齢者」(2025-09-14 公表)**
   - URL: https://www.stat.go.jp/data/topics/topi1460.html
   - 本文「Ⅰ 高齢者の人口」PDF: https://www.stat.go.jp/data/topics/pdf/topi146_01.pdf
   - 2025-09-15 現在推計。65歳以上 3,619万人、高齢化率 29.4% (過去最高)
   - 抽出する表:
     - 表1: 年齢3区分別人口及び割合 (2024年/2025年、男女別、65+・70+・75+・80+・85+・90+・95+・100歳以上)
     - 表2: 65歳以上人口及び割合の推移 (1950年〜2050年。1950–2020は国勢調査、2024–2025は人口推計、2030以降は社人研の将来推計・出生中位/死亡中位)
     - 表3: 65歳以上人口の割合 上位10か国 (2025年。日本29.4%で38か国中1位)
   - 抽出方法: `pdftotext -layout` のテキストから整形 (数値は既知の公式値でアサート)
   - 2026年版は未公表のため、これが最新 (Web検索で確認済み)
2. **人口推計 (2024年(令和6年)10月1日現在) 確報 — 第3表**
   - URL: https://www.stat.go.jp/data/jinsui/2024np/index.html
   - Excel: https://www.stat.go.jp/data/jinsui/2024np/zuhyou/05k2024-3.xlsx (都道府県、年齢3区分、男女別人口—総人口)
   - 用途: 47都道府県の65歳以上人口割合 (高齢化率) を算出。既知値: 秋田県 39.5% が最高
   - 都道府県別の最新確報。2025年10月1日現在の確報は未公表 (index2.html で確認済み)

### データフロー

1. `scripts/fetch.py`: 統計局サイトから PDF/Excel を `data/raw/` にダウンロード (HTTP ステータスとファイルサイズを検査) し、PDF は `pdftotext -layout` で `topi146_01.txt` に変換する
2. `scripts/build.py`:
   - `data/raw/topi146_01.txt` から表1・表2・表3 の数値を取得。既知の公式値 (3,619万人 / 29.4% / 前年差 −5万人 / 秋田 39.5% 等) と照合するアサーションを含む
   - `05k2024-3.xlsx` を pandas+openpyxl で読み、47都道府県の 65歳以上割合を計算
   - 全データを JSON として埋め込んだ自己完結 `index.html` を生成
3. GitHub Pages: `main` ブランチの `/` (root) を公開

### ページ構成 (index.html、日本語 UI)

- ヘッダー: タイトル、データ基準日・出典
- 要約カード ×4: 65歳以上人口 3,619万人 / 高齢化率 29.4% / 前年差 −5万人 / 75歳以上 2,124万人 (17.2%)
- チャート1 — 長期推移 (1950→2050): 65+/70+/75+/80+ 人口の折れ線 (左軸) + 65歳以上割合 (右軸)。2030年以降の将来推計は破線で区別
- チャート2 — 都道府県別高齢化率ランキング: 47都道府県の横棒グラフ (降順、2024-10-01 現在)
- チャート3 — 年齢階級別内訳: 65+・70+・75+・80+・85+・90+・95+・100歳以上の棒グラフ (男女別、2025-09-15 現在)
- チャート4 — 国際比較: 上位10か国の高齢化率 棒グラフ (日本を強調)
- フッター: 出典リンク (統計トピックス No.146、人口推計)、基準日の注記、「2024/2025年の基準日が異なる」注記

### 技術スタック

- ビルド: Python 3 + `uv run` (PEP723 インライン依存: pandas, openpyxl)。pandas 2.3.3 / uv 0.12.9 は導入済み確認済み
- PDF 抽出: `pdftotext -layout` (poppler、導入済み確認済み)
- グラフ: Chart.js v4 (CDN)。ビルド工程不要のバニラ JS
- フォント: システムフォントスタック (日本語)

## エラーハンドリング

- ダウンロード失敗: HTTP ステータス非200や小さすぎるファイルで即エラー終了
- Excel 構造変化: 期待セル位置・シート名が違えば例外で停止 (誤データを静かに出さない)
- 数値検証: build.py 内で既知の公式値をアサート (3619, 29.4, 2124, 17.2, 秋田39.5 等)
